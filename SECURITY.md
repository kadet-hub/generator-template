# Security

Report a vulnerability in this repository privately through GitHub's
private vulnerability reporting: Security tab, "Report a vulnerability".
Without a GitHub account, write to security@kadet-hub.org. Do not open a
public issue.

A version listed on kadet-hub.org that behaves maliciously is reported to
the marketplace instead, as
[its SECURITY.md](https://github.com/kadet-hub/registry/blob/main/SECURITY.md)
describes.

Only the newest released version gets fixes. Reports are handled on a
best-effort basis, without a fixed response time.

A fixed vulnerability is published as a GitHub security advisory with the
affected versions and a CVSS score.
